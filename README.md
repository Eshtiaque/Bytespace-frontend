# ByteSpace - E-Learning Platform UI

A pixel-perfect, highly responsive e-learning platform UI built with React and Tailwind CSS. Designed to deliver a seamless user experience with clean code architecture, modular components, and modern frontend practices.

## 🚀 Live Demo
* **Live URL:** `[]`


## 🛠️ Tech Stack
* **Frontend:** React.js, Tailwind CSS
* **Routing:** React Router DOM (v6.4+)
* **Assets:** Custom SVGs

## ✨ Key Highlights
* **Pixel-Perfect Responsive:** Flawless layout adaptation across Mobile, Tablet, and Desktop screens.
* **Modular Architecture:** UI is broken down into small, reusable, and maintainable components (e.g., `AboutTab`, `LessonTab`, `SidebarCard`).
* **Optimized Navigation:** Custom built, z-index-optimized mobile overlay menu with background scroll-locking for a premium UX.
* **Clean Codebase:** Strict adherence to the provided design system without redundant classes or unnecessary global states.

## ⚙️ Quick Start

```bash
# Clone the repository
git clone [repository-url]

# Navigate to the project directory
